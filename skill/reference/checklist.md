# Documentation Checklist — Evidence Standard per Deduction

Generate a filing-ready checklist of supporting documents required for every position taken in the computation. Without the paper, the deduction is at risk.

---

## Core Principle

> A deduction exists on paper until LHDN asks for proof. Then it exists only if you can produce the document.

Every claim in a tax computation requires a **specific document** that a practitioner must have in the file before filing. This checklist is generated FROM the computation — tailored to what was actually claimed.

---

## Universal Documents (every entity, every filing)

```
ALWAYS REQUIRED:
  □ Audited / management financial statements for the basis period
  □ Trial balance (detailed, not summary)
  □ Fixed asset register (cost, date acquired, category, disposal if any)
  □ Bank statements for the basis period
  □ Form C / BE / P / TF (as applicable)
  □ Prior year tax computation (for carry-forward verification)
  □ CP204 estimate and payment schedule
  □ SSM company profile / partnership registration (current extract)
  □ Board resolution for FYE (if changed)
  □ Tax agent authorisation (Form CP600B)
```

## Per-Item Documentation

### Add-Backs

| Item claimed as add-back | Document required | Why |
|--------------------------|-------------------|-----|
| Depreciation | Fixed asset register + accounts note | Confirms quantum matches accounts |
| Entertainment (50%) | Entertainment log: date, persons, business purpose, receipts | Proviso 100% items need separate proof |
| Entertainment (100% proviso) | Staff list matching event, invitation, receipts, board/management meeting minutes | Without this, LHDN defaults to 50% |
| General provision | Provision schedule + basis of computation | Proves not specific (specific = deductible) |
| Capital expenditure | Invoice + GL code + explanation of capital nature | In case LHDN queries classification |
| Penalty/fine | Notice of penalty from relevant authority | Confirms not deductible |
| Private expenses | Director's declaration or board minutes identifying private element | Defence if LHDN challenges apportionment |
| Unrealised forex (capital) | Loan agreement showing non-trade nature | Trade forex IS deductible; capital is not |
| Non-deductible interest (s.140C) | Earnings stripping computation + loan agreements | Supports the disallowance quantum |

### Deductions (beyond standard expenses)

| Deduction claimed | Document required | Why |
|-------------------|-------------------|-----|
| Bad debt (specific) | Board resolution to write off + evidence of recovery attempts (demand letters, legal, insolvency notice) | PR 04/2019 para 5.3.2 — ALL required |
| Double deduction — R&D | MOSTI approval letter (dated BEFORE expenditure) + R&D expenditure breakdown | No approval = no double deduction |
| Double deduction — training | HRDF/approved institution certificate + attendance records + invoices | Must be approved programme |
| Double deduction — export | Export promotion plan + overseas travel records + foreign advertising invoices | Must be genuine overseas marketing |
| Double deduction — disabled | JKM registration certificate for each employee + payroll records | RM registration must be current |
| Secretarial/tax fees | Invoices from company secretary/tax agent (capped RM5k + RM15k) | Must be from registered practitioners |
| Renovation allowance | Invoices + photos + R&R schedule + board approval | Must be within RM300k/3-year window |
| Donations (s.44(6)) | Official receipt from s.44(6) approved body | Receipt must state approval reference |
| Zakat (company) | Zakat payment receipt from state Islamic authority | Must be from approved body |

### Capital Allowances

| CA claimed | Document required | Why |
|------------|-------------------|-----|
| Standard CA | Purchase invoice + delivery note + evidence asset in use at period end | "In use" is the test, not just "owned" |
| Budget 2026 ACA | Invoice dated 11 Oct 2025 - 31 Dec 2026 + LOCAL manufacturer certificate (for plant/machinery) | ACA denied without local cert |
| Automation CA (200%) | MIDA confirmation letter + invoice + evidence of IR 4.0 element | Must pre-apply to MIDA |
| Small value asset | Individual invoices each ≤ RM2,000 + asset listing | Cannot aggregate to create SVA |
| Motor vehicle | Vehicle registration card (owner = company) + log book (if claiming apportionment) | QE cap verification |
| HP asset | HP agreement + payment schedule + proof of payments MADE in period | QE = capital paid, not total cost |
| Balancing charge/allowance | Disposal agreement/invoice + original QE + CA schedule showing TWDV | Proves gain/loss computation |
| Industrial building | Building plan + CF + title showing ownership + building cost breakdown | Separate building from land |

### Incentives

| Incentive claimed | Document required | Why |
|-------------------|-------------------|-----|
| Pioneer Status | MIDA PS approval letter + annual compliance report | Verify conditions still met |
| Investment Tax Allowance | MIDA ITA approval letter + QCE schedule + utilisation computation | Must track against cap |
| Reinvestment Allowance | RA claim form + QCE schedule + evidence of qualifying activity | Must be genuine reinvestment |
| GITA | MIDA GITA approval + MyHIJAU certification (if applicable) + QCE schedule | Approval BEFORE expenditure |
| JS-SEZ | IRDA/relevant authority approval + substance evidence (employees, premises, expenditure) | Ongoing substance requirements |

### WHT Compliance

| WHT obligation | Document required | Why |
|----------------|-------------------|-----|
| s.109 (royalties to NR) | WHT return (CP37) + proof of remittance + DTA claim form (if reduced rate) | Non-deductible if WHT not remitted [s.39(2)] |
| s.109B (special classes — technical/management fees) | WHT return (CP37A) + contract + proof of remittance | 10% or DTA rate |
| s.107A (contract payments to NR) | WHT return + contract + proof of remittance | 10% + 3% (13% total) |
| DTA reduced rate | Certificate of Residence from foreign tax authority + DTA claim form (CF series) | Without CoR, domestic rate applies |

### Related Party / Transfer Pricing

| Situation | Document required | Why |
|-----------|-------------------|-----|
| ANY controlled transaction > RM50k | Transfer Pricing Documentation (contemporaneous) | Mandatory under TP Rules 2012 |
| Group revenue ≥ RM25m OR RP transactions ≥ RM15m | Full TP documentation set | Threshold for mandatory documentation |
| Management fee from/to related party | Service agreement + time records + benefit test + benchmarking | Most commonly challenged by LHDN |
| Intercompany loan | Loan agreement + market rate evidence + interest computation | Earnings stripping computation if > RM500k |

### Losses and Carry-Forwards

| Position | Document required | Why |
|----------|-------------------|-----|
| B/F losses claimed | Loss memorandum with year of origin + computation for each year | LHDN verifies year-by-year |
| Shareholder continuity | SSM returns for EACH year from loss year to current (showing shareholders) | s.44(5A) test is annual |
| Group relief (s.44A) | Joint election form + both companies' computations + ownership evidence | All 10 conditions documented |
| Unabsorbed CA c/f | Prior year CA schedules + asset register (assets still owned/in use) | Cannot claim CA on disposed assets |

## E-Invoice Requirements (from 1 July 2025)

```
ALL B2B TRANSACTIONS require validated e-invoice:

FOR EXPENSES CLAIMED AS DEDUCTION:
  □ Received e-invoice from supplier (validated by LHDN MyInvois)
  □ OR self-billed e-invoice (for imports, foreign suppliers, employees)
  □ OR consolidated e-invoice (for transactions ≤ RM500 with non-business buyers)

WITHOUT VALID E-INVOICE:
  → Expense deduction is at risk from 1 January 2026
  → Transition period (1 Jul 2025 - 31 Dec 2025): manual invoice still accepted
  → From 1 Jan 2026: e-invoice required for tax deduction claim

SELF-BILLED E-INVOICE needed for:
  □ Foreign payments (royalties, technical fees, services)
  □ Employee reimbursements > RM500/month
  □ Interest payments to individuals
  □ Rental to individual landlords
  □ Agent/distributor commissions
```

## Checklist Generation Rules

When generating a checklist from a computation:

```
1. READ the computation line by line
2. FOR EACH add-back, deduction, CA claim, incentive, WHT obligation:
   → Map to the documentation table above
   → Generate specific document requirement
3. FLAG items where documentation may be MISSING:
   → "Bad debt write-off claimed RM120k — do you have board resolution + recovery evidence?"
   → "ACA claimed — do you have local manufacturer certificate?"
4. PRIORITISE by risk:
   → P0: Claims that will be DENIED without the document (WHT, incentive approvals)
   → P1: Claims likely to be QUERIED (entertainment 100%, TP, large donations)
   → P2: Standard documentation (invoices, FA register)
5. OUTPUT as actionable checklist with status column: [✓ Have] [? Check] [✗ Missing]
```

## NEVER

- Generate a generic checklist not tied to the actual computation (every item must trace to a specific claim)
- Mark a document as "optional" when it's required for the deduction to survive audit
- Forget e-invoice requirements for basis periods starting 1 July 2025
- Skip WHT documentation (s.39(2) = automatic disallowance without remittance proof)
- Assume the client "probably has" a document — ask explicitly and flag if unconfirmed
- List documents without explaining the consequence of not having them
